## Make template maps readable

Load RPG Maker MV or MZ map JSON and arrange its event markers into labeled groups. Use tags and prefab group styles to give a crowded template map a layout you can understand at a glance.

## Export an editor reference

Save your layout separately and export a PNG you can use as a parallax reference in RPG Maker. The standalone Windows app reads the map data and saves its work in separate files. It works with standard MV and MZ maps, including projects that use other event-spawning tools.
