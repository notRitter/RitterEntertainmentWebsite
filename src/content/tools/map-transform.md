## Change tiles at runtime

Edit tile layers, shadows, and region IDs, or copy tiles from another map. Swap a single tile or an area and decide whether a change should persist.

## Reuse map sections

Prepare a set of tiles on a template map and use it as a prefab on the active map. Each edition has its own storefront listing with setup instructions and engine-specific details.
